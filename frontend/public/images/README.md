# Foto kedai

Taruh foto asli dari pemilik di folder ini dengan nama persis seperti di bawah.
Selama file belum ada, website otomatis menampilkan ilustrasi pengganti.

Minta izin dan file aslinya ke pemilik (Pak Alfian), jangan unduh dari Instagram atau Google Maps.
Foto di Google Maps sebagian besar diunggah pengunjung, jadi hak ciptanya milik mereka.

| Nama file | Isi foto | Dipakai di |
|---|---|---|
| `jendela-merapi.jpg` | Pemandangan Merapi dari jendela kedai (potret, 4:5) | Hero landing page |
| `suasana-sore.jpg` | Pengunjung duduk di jendela saat sore/sunset | Galeri (besar) |
| `lampu-anyaman.jpg` | Lampu anyaman menyala di malam hari | Galeri |
| `wedang-uwuh.jpg` | Wedang uwuh dalam karaf/gelas di meja kayu | Galeri |
| `bangku-jadul.jpg` | Bangku & meja kayu jadul | Galeri |

Foto menu: simpan sebagai `menu/<id-menu>.jpg` (contoh `menu/wedang-uwuh.jpg`),
lalu isi `image: '/images/menu/wedang-uwuh.jpg'` pada item di `src/data/menu.js`.
Ukuran disarankan maksimal 1600px di sisi terpanjang, format JPG/WebP.
